# 인생게임 (HTTP 턴제 멀티플레이)

브라우저로 접속하는 턴제 인생게임 서버. 라즈베리파이 4에서 Node.js 단일 프로세스로 구동합니다.
전체 설계는 [`docs/PLAN.md`](docs/PLAN.md)를 참고하세요. (현재: 5단계 2D 컷인·사운드 — 엔진 코어·에셋 스튜디오·3D 말판 포함)

## 실행

Node.js 20 이상이 필요합니다.

```bash
npm install          # postinstall이 three.js를 public/vendor/three/ 로 복사 (CDN 없이 LAN에서 동작)
ADMIN_PASSWORD=원하는비밀번호 npm start     # 개발 중 자동 재시작: npm run dev
```

`ADMIN_PASSWORD`를 설정하지 않으면 첫 실행 때 10자리 비밀번호를 만들어 콘솔에 **한 번** 출력하고
`DATA_DIR/admin-password`(권한 600)에 저장합니다. 다음 실행부터는 그 파일의 비밀번호를 씁니다.
관리자 로그인은 7일 유지되며(`DATA_DIR/admin-sessions.json`, 토큰 해시만 저장) 서버를 재시작해도 풀리지 않습니다.
로그인 시도는 IP당 1분에 10회로 제한됩니다.

- 게임 페이지: `http://<서버주소>:3000/`
- 관리자 페이지: `http://<서버주소>:3000/admin`

| 환경변수 | 기본값 | 설명 |
|---|---|---|
| `PORT` | `3000` | 서버 포트 |
| `ADMIN_PASSWORD` | (자동 생성) | 관리자 비밀번호. 없으면 `DATA_DIR/admin-password`에 만들어 저장 |
| `DATA_DIR` | `./data` | 방 스냅샷(`saves/<roomId>.json`)·세션 저장 폴더 |

리눅스에서는 서버가 시작할 때 `MALLOC_ARENA_MAX=2 MALLOC_MMAP_THRESHOLD_=131072`로 자기 자신을 한 번 다시 실행합니다
(AI 일러스트 3건 후 메모리 약 420MB → 160MB). Node 22.15 미만이면 이 두 환경변수를 직접 설정하세요.

## 사용 흐름

1. `/admin`에서 로그인 → 모드·시대별 턴 수·최대 캐릭터·초기 자금·턴 제한 시간(끄기/30/60/90/120초)을 정해 방 생성 →
   6자리 방 코드 확인. 청년·중년은 3턴 이상, 어린 시절 모드의 고등학생은 2턴 이상이어야 한다.
2. 참가자는 `/`에서 방 코드와 이름으로 입장(`/?code=ABC123` 링크도 가능) → 캐릭터를 꾸며 여러 명 생성.
   **관전**으로 들어가면(진행 중·종료된 방도 가능, 4명 제한에 포함 안 됨) 캐릭터·행동 없이 보고 리액션만 보낸다.
3. 관리자가 캐릭터 2명 이상일 때 게임 시작 → 시드로 시대별 보드가 생성되고 가문 순서로 턴이 돈다.
4. 내 캐릭터 차례에 「룰렛 돌리기」(1~10). 청년·중년 시대 시작의 「인생 갈림길」에서 💕 연애·육아 / 💼 일·커리어 /
   💰 보물·부동산·금전 루트를 고르고, 시대 끝 합류 칸에서 다시 만난다. 고등 시대 첫 칸은 수능(정지칸).
5. 남의 턴(룰렛 전)에는 **훈수 베팅**: 홀/짝(×2), 1~3·4~6(×3), 7~10(×2.5)에 5~20만원(어느 쪽도 기대값이 +가 아님,
   당첨금은 내림). 룰렛이 돌면 마감·정산.
6. 생일 파티 같은 **동시 입력** 이벤트는 모든 대상이 답하거나 제한 시간(40초)이 지나면 기본 선택으로 처리된다.
   턴 제한 시간을 켠 방은 시간이 지나면 룰렛을 자동으로 돌리고, 혼자 고르는 선택은 기본값으로 처리한다.
7. 처음으로 누군가 노년에 들어설 때 순자산 하위 2명(3캐릭터 이상)을 **기초연금** 대상자로 한 번만 정하고, 각자 노년에
   들어설 때 지급한다(역전 보정). 골인 순서대로 상금(200·150·120·90·60·40·20·10만원), 골인 후엔 매 턴 보너스 룰렛(×5만원).
8. 모두 골인하면 결과 발표(현금 − 빚 순위). 관리자는 강제 종료(현재 자산 순위)·선택 강제 시간초과·룰렛 대신 돌리기·
   턴 넘기기가 가능하다.

규칙 수치는 `server/data/board.json`(칸 풀·가중치·루트 풀·이벤트), `balance.json`(룰렛·베팅·연금·골인 상금),
`eras.json`(시대·기본 턴 수)에서 조정한다.

## 3D 말판 (4단계)

게임 화면의 말판은 Three.js 3D로 그려집니다(마을 위 트랙·사각 타일·청년/중년 3갈래 루트 리본, 파츠 조합 말,
대형 룰렛, 이동 애니메이션, 표정·이모지 팝업). WebGL이 없거나 느리면 2D 간이 보드로 자동 전환됩니다.

- **2D/3D 전환**: 말판 오른쪽 위 「2D 보기 / 3D 보기」 버튼(선택은 브라우저에 저장). URL `?board=2d`도 가능.
  자동 모드에서는 처음 3초 평균이 15fps 미만이면 안내 후 2D로 바뀝니다(버튼으로 다시 켤 수 있음).
- **카메라**: 드래그 회전 · 핀치/휠 확대 · 두 손가락(또는 우클릭/Shift 드래그) 이동, 「🎥 카메라 리셋」.
  남의 차례에는 현재 말을 자동으로 클로즈업(관전 스포트라이트), 시대 탭을 누르면 그 시대 전체를 보여 줍니다.
  내 차례에는 오른쪽 위 작은 룰렛을 눌러도 돌릴 수 있어요.
- **그래픽 품질**: 말판 위 선택 상자 또는 URL `?quality=`

| 값 | 설명 |
|---|---|
| `high` | 화면 해상도 그대로, 파티클·궤도 카메라 (8코어 이상 PC/폰 기본값) |
| `low` | 75% 해상도·30fps 제한·소품/파티클 축소 (4코어 이하·저사양 폰 기본값) |
| `tv` | 720p로 렌더 후 브라우저가 확대, 파티클 없음, 고정 조감 카메라 — 라즈베리파이 TV 화면용 |

- **라즈베리파이 TV 모드**: Raspberry Pi OS(Bookworm) Chromium을 GPU 가속으로 키오스크 실행하세요.

```bash
chromium-browser --kiosk --ignore-gpu-blocklist --enable-gpu-rasterization \
  "http://localhost:3000/?quality=tv"
```

  `chrome://gpu`에서 WebGL이 "Hardware accelerated"인지 확인하세요(가속이 꺼지면 4~5fps → 2D로 전환됨).
- **glTF 말 교체(선택)**: `public/assets/models/pawn.glb`를 넣으면 기본 로우폴리 말 대신 사용합니다.
  재질 이름에 `skin`/`hair`/`outfit`이 들어간 부분은 캐릭터 파츠 색으로 칠해집니다.
- 에셋 스튜디오에서 `icon-*`(타일 아이콘)·`tex-grass`(잔디)가 채택되면 3D 말판에 자동 반영됩니다.
- 성능 예산: 드로우콜 100 이하·삼각형 5만 이하(8캐릭터 인생 전체 보드 실측 약 32콜·2.1만 삼각형).

## 이벤트 컷인·사운드 (5단계)

말판은 3D, 이벤트는 원작처럼 **2D 일러스트 컷인**으로 전환됩니다. 이벤트·하트·직업·카드·상점·보물·부동산·정지 칸
도착, 시대 진입, 루트 선택, 골인, 수능/생일 결과, 모든 선택(프롬프트)이 컷인으로 나오고, 돈/지출 칸은 말판 위
떠오르는 금액으로만 표시됩니다.

- 구도: **톤별 프레임 패턴**(연애 분홍·커리어 파랑·보물 금색·좋은 일 초록·나쁜 일 남색·명절 빨강·결과 보라) →
  16:9 일러스트 창(장소별 생성 배경 + 내 캐릭터) → 노란 테두리 대사 상자(▼ / 화면 탭 / Enter·Space로 넘김) →
  캐릭터 탭. 모바일은 같은 구도를 세로로 쌓고 창은 16:9를 유지합니다.
- 말풍선 대사는 `server/data/lines.json`(상황 태그별 반말 드립)에서 서버가 시드로 골라 **모두에게 같은 대사**가 보입니다.
  톤·프레임·색·효과음·장소 매핑은 `server/data/tones.json`에서 조정합니다.
- 캐릭터는 생성된 PNG 레이어(키포즈·표정·의상)를 아바타 머리색·의상색·피부색으로 **다시 칠해** 합성하고,
  숨쉬기·통통 튀기·스쿼시&스트레치·포즈 크로스페이드·눈물/땀/하트 파티클, 큰 이득엔 점프 스프라이트를 재생합니다.
  레이어가 없으면 SVG 초상화로 대신합니다.
- 선택지는 대사 상자 안의 버튼으로 고릅니다. 다른 사람은 「○○의 선택을 기다리는 중…」 컷인을 보며 이모지 리액션을
  보낼 수 있고, 리액션은 일러스트 창 아래에 표시됩니다. 관전자 컷인은 4초 뒤 자동으로 넘어갑니다.
- 결과 화면은 「🏆 결과 발표」 컷인 뒤에 순위표가 나옵니다.
- **사운드**: Web Audio로 합성한 효과음(룰렛 틱, 코인, 둥-, 팡파레, 하트, 휙, 뽁, 눈물)과 시대별 잔잔한 배경음.
  말판 도구줄의 🔊/🔇(음소거)·🎵 BGM·🎬 컷인 버튼으로 켜고 끄며, 설정은 브라우저에 저장됩니다.
  모바일 자동재생 정책 때문에 첫 터치/클릭 후부터 소리가 납니다.
- 오디오 드롭인(선택): `public/assets/audio/bgm_<era>.mp3`(예: `bgm_elem.mp3`)가 있으면 그 시대 배경음으로,
  `sfx_<name>.mp3`(`coin`, `thud`, `fanfare`…)가 있으면 합성 효과음 대신 재생합니다(목록은 `GET /api/audio`).
- URL `?cutins=off`로 컷인 없이(말판 연출 + 선택 모달만) 볼 수 있습니다.

## 에셋 스튜디오 (3단계, Gemini 이미지 생성)

게임 그래픽(컷인 배경·캐릭터 레이어·키포즈·스프라이트·아이콘·텍스처·프레임)은 Gemini
(`gemini-2.5-flash-image`, "Nano Banana")로 생성해 `public/assets/generated/`에 저장합니다.
에셋이 아직 없으면 게임은 SVG/프리미티브 자리표시자를 그대로 씁니다.

- 키 설정: 환경변수 `GEMINI_API_KEY`(우선) 또는 `/admin/assets`에서 입력 → `data/secrets.json`(권한 600, gitignore).
  키는 브라우저·응답·로그로 절대 나가지 않습니다.
- 관리자 화면 `http://<서버주소>:3000/admin/assets`: 항목 선택 → 프롬프트 수정(선택) → **변형 4장 생성** →
  후보 미리보기 → **채택** / 재생성 / 이미지 **업로드로 교체**. 채택하면 `public/assets/generated/<output>`에
  저장되고 `server/assets/manifest.json`의 상태가 `accepted`로 바뀝니다(둘 다 커밋 대상).
- 순서: 스타일 앵커(`style-anchor`)를 먼저 채택해야 나머지(참조 이미지로 첨부)를 만들 수 있고,
  키포즈·표정·의상은 캐릭터 베이스(`char-schoolgirl-base`) 채택 후 생성됩니다.
- 배치 CLI:

```bash
node scripts/gen-assets.js --only style-anchor --accept-first   # 1장 생성 후 바로 채택
node scripts/gen-assets.js --kind bg --count 2                   # 배경 전부 후보 2장씩
node scripts/gen-assets.js --all --accept-first --dry-run        # 호출 수만 미리 보기
```

| 환경변수 | 기본값 | 설명 |
|---|---|---|
| `GEMINI_API_KEY` | (없음) | Gemini API 키. 없으면 생성 불가(업로드·기존 에셋은 동작) |
| `GEMINI_MODEL` | `gemini-2.5-flash-image` | 이미지 모델 ID (매니페스트 `settings.model`보다 우선) |
| `ASSET_DAILY_CAP` | `300` | 하루(UTC) 최대 생성 호출 수. 사용량은 `data/assets-usage.json` |

안전장치: 동시 요청 2개, 429/5xx 재시도 3회(지수 백오프), 일일 한도, 채택된 에셋은 강제 재생성 전까지 다시 만들지 않음.
후보 이미지는 `data/asset-candidates/<id>/`에 쌓이며 관리자 화면에서 지울 수 있습니다.

## Customization UI (Stage 5.5-A)

로비의 「+ 캐릭터 만들기」/「편집」은 전체 화면(모바일)·가운데 모달(데스크톱) 커스터마이저를 엽니다.

- 탭 5개: **체형**(체형·체격·피부) / **얼굴**(얼굴형·눈·입·볼) / **머리**(모양 20·색) / **옷**(의상 30·색) / **소품**.
- 색은 동그란 스와치, 나머지는 해당 부위를 확대한 썸네일로 고릅니다. 모바일에서 항목이 많은 그리드는 2줄 가로 스크롤.
- 키보드: 탭·옵션에서 방향키로 이동, Enter로 선택, Esc로 닫기.
- 큰 미리보기: 2D 초상화(표정 칩 기본·기쁨·울음·놀람) ↔ 3D 말 토글(2D 보드 모드이거나 WebGL이 없으면 숨김).
- 의사 가운·경찰 제복·요리사복·태권도 도복은 고유 색이라 의상 색 선택이 잠깁니다.
- 🎲 전체 랜덤 / 🎲 이 탭만 랜덤, 이름 입력, 저장·취소. 예전에 만든 캐릭터는 새 항목이 기본값으로 채워집니다.

## Paper-doll layers (Stage 5.5-B)

캐릭터 커스터마이징의 2D 레이어(종이 인형) 에셋입니다. 모든 옵션이 같은 1024×1536 캔버스·같은 정면 포즈의 투명 레이어라서 순서대로 겹치기만 하면 됩니다.

- 만드는 법: 대머리·민얼굴 마네킹(체형 2 × 체격 3)을 Gemini로 한 번 그린 뒤, "다른 건 그대로 두고 X만 추가" 편집을 하고
  마네킹과의 **차이만 추출**(`diffExtract`)합니다. 머리카락·의상은 중립 회색으로 생성해 브라우저에서 색을 입힙니다(`tintMath`).
- 레이어 순서: 뒷머리 → 마네킹(피부색) → 얼굴형 → 의상(의상 색) → 볼 → 눈(깜빡임/표정) → 입 → 앞머리(머리색) → 모자류 → 액세서리.
- 파일: `public/assets/generated/parts/…` (WebP, 약 11MB). 목록·메타는 `server/assets/manifest.json`의 `kind: "part"` 항목,
  게임은 `GET /api/assets`로 받습니다.
- 새 옵션 추가:
  ```bash
  # 1) server/data/avatars.json 에 옵션 추가 (promptDesc 포함)
  node scripts/gen-part-manifest.js                                  # 매니페스트에 part 항목 추가(채택된 항목은 유지)
  node scripts/gen-assets.js --kind part --accept-first --parallel 2 # 생성·채택 (마네킹 → 부위 순서 자동)
  node scripts/part-qa.js --fix                                       # 자동 검수, 이상한 레이어 재생성(최대 2회)
  node scripts/part-sheets.js --out /tmp/sheets                       # 콘택트 시트로 눈으로 확인
  ```
- 추출 알고리즘을 고친 뒤에는 `node scripts/part-qa.js --reprocess`로 API 호출 없이 전부 다시 추출할 수 있습니다.

## AI character art (Stage 5.5-D)

로비에서 캐릭터를 저장한 뒤 편집 화면 아래의 **✨ AI 일러스트 만들기** 버튼으로, 고른 모습 그대로의 고품질 일러스트
(기본 전신 1장 + 포즈 6장 + 표정 4장 = 11장)를 Gemini로 만듭니다. 서버에 Gemini 키가 있을 때만 버튼이 보입니다.

- 요청 횟수로 제한합니다(실패·취소돼도 1회로 셈): 캐릭터마다 1번, 한 사람당 방마다 2번(캐릭터를 지우고 다시 만들어도
  유지), 방 전체 8번(`balance.json` `charArt`). 다시 만들기는 관리자만(`?force=1`은 방 한도도 무시):
  `POST /admin/api/rooms/<방>/characters/<캐릭터>/art?force=1`.
- 같은 모습은 `DATA_DIR/char-art/<해시>/`에 저장되어 다른 방·다른 판에서도 즉시 재사용됩니다. 일일 생성 한도는 에셋 스튜디오와 공유합니다.
- 생성 중에는 진행률(n/11)이 로비에 표시되고, 게임 시작은 기다리지 않습니다. 서버를 재시작하면 진행 중이던 작업은 실패(서버 재시작)로 바뀝니다.
- 크레딧이 없으면(HTTP 402) "AI 생성 크레딧이 부족합니다. 관리자에게 문의하세요."로 실패 처리됩니다.

실제 생성(크레딧 충전 후):
```bash
export GEMINI_API_KEY=...          # 또는 /admin/assets 에서 키 저장 (DATA_DIR/secrets.json)
npm start                          # /api/meta → features.charArt: true
# 로비 → 내 캐릭터 편집 → ✨ AI 일러스트 만들기
```

API 없이 흐름만 확인(테스트 전용): `CHAR_ART_FAKE=1 DATA_DIR=/tmp/jinsei-smoke npm start`
(`CHAR_ART_FAKE=402`는 크레딧 부족 흉내). 운영에서는 절대 켜지 마세요.

## MC NPCs (Stage 5.6)

게임 진행을 두 마리 시츄 **호야**(리액션·분위기 담당, 해맑은 장난꾸러기, 반말 "~멍!")와 **봄이**(진행·해설 담당, 시크한 츤데레,
짧은 존댓말 "…그렇습니다", 가끔 "흥")가 MC로 맡습니다.

- **로비**: 두 MC가 환영 인사(✕로 닫기). **게임 시작·새 시대 첫 진입·결과 발표**는 「인생 방송국」 스튜디오에서 두 MC가 화면
  중앙에 나오는 MC 컷인으로 진행됩니다. 결과 발표는 봄이가 발표하고 호야가 리액션하며, 1등·꼴찌·벌칙 멘트까지 이어집니다.
- **이벤트 컷인**: 큰 이벤트(연애·취업·보물·대박·큰 손실·파산·골인…) 때 컷인 오른쪽 아래에 MC가 작게 나와 한마디(두 MC 만담 포함).
  컷인이 없는 순간(첫 룰렛 안내, 돈 칸, 훈수 적중 등)은 게임 화면 오른쪽 아래 코너에서 말합니다. 말할 때 「멍!」 효과음(음소거 존중).
- **3D 말판**: 현재 시대 시작 지점 옆에 로우폴리 강아지 마스코트 2마리(꼬리 흔들기, 큰 이벤트 때 점프·회전, 이모지 반응 때 카메라 보기).

  쿨다운(연속 등장 방지). 끄기는 로비 인사·컷인·코너·3D 마스코트를 모두 숨깁니다.
- 그림: 지금은 사진을 보고 그린 **SVG 치비 강아지**가 나오고, 생성 그림이 채택되면 자동으로 바뀝니다.

실제 MC 그림 생성(Gemini 크레딧 충전 후). 사진 원본은 `DATA_DIR/mc-refs/`(기본 `data/mc-refs/`, gitignore)에만 두세요 —
`hoya-1.jpg hoya-2.jpg bomi-1.jpg bomi-2.jpg duo.jpg`. 생성할 때만 참조 이미지로 읽고 공개되지 않습니다.

node scripts/gen-assets.js --kind mc --accept-first --parallel 2  # 기본(neutral) → 표정 6 + 포즈 3 → 듀오 순서 자동

`--accept-first` 대신 `/admin/assets`에서 후보를 보고 채택해도 됩니다(항목당 후보 3장).

## 6단계 — 능력치·직업·성장 (규칙·서버)

- **능력치 4종** 지력·체력·매력·운(0~10). 시작은 모두 2 + 랜덤 1점(어른 모드는 +5점). 아기~고등 시대의 **습관 칸**에서

  졸업·승진으로도 오릅니다. 야근·회식 이벤트는 체력을 깎아요.
- **수능**(고등학생 첫 칸): 차근차근(지력 승부) / 찍기(운 승부) → 명문대 · 일반대 · 불합격. 선택지에 합격 확률이 보여요.

  한 턴 쉬고 수능 재도전 — 붙으면 바로 입학). 어른 모드는 학력이 랜덤으로 정해진 채 시작합니다.
- **군 복무**: 남자는 필수(대학생은 「지금 입대 / 졸업 후 입대」 선택, 그 외는 취업 후 자동 입대 — 직업은 유지), 여자는 체력 4
  이상이면 자원 입대 선택. 복무 중 룰렛 2번은 절반만 이동하고 군 월급을 받으며, 전역하면 체력 +2.
- **직업 23종**: 일반 17종(공무원·대기업 회사원·웹툰 작가·국회의원·야구선수·축구선수·e스포츠·격투기·배우·아이돌·유튜버·셰프·
  의사·연구원·경찰관·개그맨·교사) + 숨은 직업 6종. 취업 제안은 요구 능력치·학력(+뉴스)을 만족하는 직업 중 3개(어려운 직업일수록
  잘 나옴), 하나도 없으면 **알바**부터. 직업마다 랭크 3~5단계와 급여, 스포츠·격투기는 부상 위험.

  체력 −1), 최고 랭크면 성과급 협상.
- **숨은 직업**: 우주비행사(지력·체력 9), 국민 MC(개그맨·배우·유튜버 최고 랭크 + 매력 9), 재벌 총수(대기업 임원 + 순자산

  숨은 직업 해금(금빛 반짝임), 부상(병원·🤕), 입대 배웅·전역 알림, 졸업(학교·🎓). 다른 사람의 취업·승진·숨은 직업·뉴스는
  「관전 컷인: 간단히」에서도 큰 컷인, 습관·월급 칸은 작은 알림.
- **선택지**: 습관·진로·군 복무·취업 제안·직업 칸·숨은 직업 제안이 컷인 선택지로 나오고, 취업 제안에는 직업 아이콘·첫 월급·
  요구 능력치/학력 배지가 붙어요.
- **시대 뉴스**: 상단의 📰 배지(누르면 내용), 시대가 열릴 때 MC 방송국 컷인에 「📰 속보」 자막 + 말판 배너.
- **말판**: 습관·월급·직업 칸 색·아이콘(2D/3D).

## 7단계 — 카드·아이템·상호작용 (규칙·서버)

- **수동 에셋 가져오기**: Gemini 앱에서 만든 그림을 `assets-inbox/<에셋 id>.png`(jpg·webp도 가능)로 올린 뒤
  `node scripts/import-assets.js` → 항목의 후처리(배경 제거·자르기·크기 맞춤)를 거쳐 채택되고 원본은 inbox에서 지워집니다
  (`--dry-run` 점검만, `--keep` 원본 유지, `--only id,id`). 오른쪽 아래 반짝이 워터마크는 자동으로 지우고, 배경 그림은
  비율이 달라도 잘라서 1920×1080으로 채워요. 프롬프트는 `docs/asset-prompts.md`. 아직 그림이 없는 새 장면(무대·경기장·
  체육관·훈련소·대학·주방·경찰서·연구실·발사장·동네 마트·명절 거실)은 기존 배경 5장 중 비슷한 것으로 대신 보여 줍니다.
- **카드 16종** (손패 최대 5장, 넘치면 가장 오래된 카드를 버림, 손패는 모두에게 공개): 카드 칸·상점·일부 이벤트에서 얻고,
  내 차례 룰렛 전에 한 턴 한 장 사용.
  - 즉시형: 스터디 모임(지력 +1), 인싸력(매력 +1), 에너지 드링크(이번 룰렛 +2칸), 택시(룰렛 두 번 중 큰 값), 공약 카드(국회의원
    전용, 다른 캐릭터 모두에게서 후원금).
  - 자동형(조건이 되면 알아서 소모): 성과급 봉투(다음 월급 2배), 실손 보험(다음 손실 절반), 건강 부적(다음 부상·나쁜 이벤트
    1회 무효), 로또 복권(다음 추첨 참가), 할인 쿠폰(상점 50%), 변호사 상담권(뒤통수 1회 자동 방어).
  - 뒤통수: 새치기(대상 다음 룰렛 −3칸, 최소 1칸), 층간소음(대상 다음 룰렛 두 번 중 작은 값), 세무조사(현금 10%, 최대
    300만원), 갑질 민원(직장인 경험치 −2, 아니면 벌금), 소문내기(매력 −1). 같은 캐릭터를 연달아(이번·지난 라운드) 노릴 수
    없고, 대상이 변호사 상담권을 가지고 있으면 두 카드가 함께 사라지며 막혀요.
- **상점 칸**(금전 루트·노년): 카드 2장 + 아이템 1개 진열, 하나 사거나 그냥 나가기(돈이 모자라면 못 고름, 쿠폰이면 반값).
  **아이템 6종**(종류별 1개): 경차(룰렛 1 → 2칸), 노트북(지력 +1, 웹툰 작가·유튜버·e스포츠 월급 +10%), 헬스 회원권(체력 +1),
  명품 가방(매력 +1, 되팔 때 90%), 복고양이(운 +1), 안마의자(노년 이벤트에서 체력 안 깎임). 최종 정산에 되팔기 가치
  (구매가 × 비율)가 더해집니다(결과 순위의 `items`).
- **거래·선물**(차례와 상관없이, 게임 진행 중 언제나): 거래 제안은 돈 또는 카드 한 가지씩 주고받기(돈↔돈 불가, 내 캐릭터끼리
  불가, 캐릭터당 대기 1건). 60초가 지나거나 제안한 캐릭터의 다음 차례가 오거나 누가 골인하면 만료. 수락할 때 조건을 다시
  확인해요. 선물은 즉시(내 캐릭터끼리도 가능 — 가족 송금).
- **명절 대잔치**(방 설정 「명절 대잔치」, 기본 켜짐): 중학생·청년·중년·노년 시대가 처음 열릴 때(그 모드의 첫 시대 제외) 설날/
  추석을 번갈아 한 번. 전원이 동시에 고스톱 판돈(구경만 / 소소하게 / 크게)을 고르면 ① 세배 룰렛(아이는 세뱃돈을 받고
  어른은 줌) ② 잔소리 룰렛(능력치 하나 ±1) ③ 고스톱 한 판 — 화투 끗수가 가장 높은 사람이 이기고, 진 사람은 각자
  (내 판돈, 이긴 사람 판돈 중 작은 값)을 냄. 돈은 판돈을 건 사람끼리만 오가요.
- **전국 로또**: 시대가 처음 열릴 때마다(명절 없는 시대 포함) 로또 복권을 가진 캐릭터가 한 장씩 써서 1~20 중 번호 3개로 추첨
  (3개 1,000만원 · 2개 100만원 · 1개 10만원, 기대값 약 8.9만원 < 카드 가격 20만원). 봄이가 방송국에서 진행해요.
- 밸런스: `node scripts/simulate.js --games 300 --seed 11` 끝의 「7단계」 블록(카드 획득·사용, 뒤통수 대상 순위, 방어,
  상점 구매율, 아이템, 명절 돈 흐름, 로또 실제 당첨금 vs 기대값, 선물·거래). `--bias --games 2000 --seed 1`은 카드 사용
  포함 턴 순서 편향.
