# 1~9단계 Opus 시뮬레이션 종합 보고서 (2026-09-27)

Opus 에이전트 4개가 서로 다른 방식으로 게임을 시험했습니다. 원본 스크립트와 스크린샷은 세션 scratchpad `sim1~sim4/`에 있습니다.

| 시뮬레이션 | 방식 | 규모 |
|---|---|---|
| 1. 밸런스·전략 | 순수 엔진 대량 시뮬레이션, 31개 고정 전략 vs CPU | 약 5.5만 판 |
| 2. 실제 플레이테스트 | 브라우저 4대(PC 3D/2D, 폰 2D/3D) + CPU, 실수 행동 포함 | 9개 세션, 인생 모드 기본 길이 1판 |
| 3. 규칙·안정성 퍼즈 | 정상·비정상 행동 무작위, 불변식 검사, 서버 부하·재시작 | 3,010판 · 49만 행동 |
| 4. UI 몽키 테스트 | 무작위 클릭·키보드·환경 변화, XSS, 잘못된 입력 | 약 30분 · 2,000 동작 |

## 잘 된 점

- **견고성**: 모든 세션에서 튕김, 콘솔 에러, 서버 5xx가 0건이었습니다. 불변식 위반과 비밀 유출도 없었습니다.
- **결정성**: 저장 후 불러오면 게임이 똑같이 이어집니다. 서버 재시작도 1.8초 만에 자동으로 재연결됐습니다.
- **XSS 방어**: 이름에 넣은 해킹 코드가 어디서도 실행되지 않았습니다.
- **연타·중복 방어**: 룰렛 25번 연타는 1번만 처리되고, 선물 20번 동시 전송도 1번만 처리됐습니다.
- **메모리**: 20판 연속으로 돌려도 157MB에서 더 늘지 않았습니다.
- **재미 포인트**: 플레이테스터가 가장 좋았다고 꼽은 부분입니다.
  - 호야·봄이 MC(대사의 85%가 고유)
  - 프러포즈·결혼·출산·돌잔치 컷인
  - 화투 명절 정산
  - 결산 방송, MVP, 단체 사진
- **게임 길이**: 인생 모드 기본 길이에 4명 + CPU 2명(8캐릭터)으로 **약 25분**이 걸렸습니다.

## C. 재미·UX (플레이테스트)

1. **기다리는 시간이 가장 큰 문제입니다.**
   - 캐릭터가 1개인 플레이어는 실제로 조작한 시간이 전체의 약 6%였습니다. 20초 넘는 대기가 15번 있었고, 가장 긴 대기는 4분이었습니다.
   - 턴이 시작되고 룰렛 버튼이 뜨기까지 평균 12.9초(상위 10%는 31.6초)가 걸렸습니다. 실제로 누르는 데는 2.4초밖에 안 걸립니다.
2. **해결 방향**
   - 다음 사람의 룰렛을 앞 연출과 겹쳐서 돌릴 수 있게 합니다.
   - 남의 컷인은 3초로 제한하고, 「⏩ 빨리 감기」 버튼을 둡니다.
   - 남의 턴에도 모두가 참여하는 작은 선택을 늘립니다(결과 맞히기 등).
   - 턴 제한 기본값을 60초로 하는 것을 검토합니다.
3. **반복되는 연출**
   - 시대 진입 컷인을 한 판에 35~40번 봤습니다. 첫 진입자만 전체 컷인으로 보여 주고 나머지는 배너로 바꿉니다.
   - 남의 결혼식은 두 번째부터 배너로 바꿉니다.
4. **반복되는 말판 대사**
   - 「그냥저냥 괜찮아」가 한 판에 70번 나왔습니다(전체 1,744줄 중 고유 399줄).
   - 무난한 칸은 대사를 생략하고, 같은 대사는 N턴 안에 다시 쓰지 않게 합니다.
5. **PC 1280×720 레이아웃**
   - 베팅이나 상세 카드를 열면 말판이 화면 밖으로 사라집니다.
   - 캐릭터 목록을 따로 스크롤되게 하고, 말판을 화면에 고정합니다.
6. **폰 결과 페이지**: 5,500px로 너무 깁니다. 상위 3명만 펼치고 나머지는 접습니다.
7. **TV 모드**: 컷인이 작습니다. 1.5배로 키웁니다.
8. **관리자 설정**: 「시대별 턴 수」는 실제로는 칸 수입니다. 「시대 길이(칸)」로 이름을 바꾸고 예상 소요 시간을 보여 줍니다.
9. **3D 첫 턴**: 첫 룰렛까지 20초 넘게 걸립니다. 개막 스튜디오 컷인이 나오는 동안 미리 빌드합니다.

## D. 운영 관련 확인 필요

- 끝난 방이 영구히 남습니다(한 판에 약 150KB). 일정 기간 뒤 자동 삭제(TTL)를 권장합니다.
- 시작 자금이 0이면 아이가 학원 칸에서 빚을 집니다(의도인지 확인 필요).
- 역방향 프록시 뒤에서 운영하면 `trust proxy`를 설정하지 않았을 때 관리자 로그인 잠금을 누구나 걸 수 있습니다.
