10. ✅ **노년 역전**(G2, 사용자 요청 「앞선 시대 아이템으로 노년 역전 · 한방역전섬 대박/쪽박」·「알아서 잘」): 노년 골인 경주에 🏝️ 한방역전섬(경주에 1칸, 지나가기만 해도 멈춤 — 💥 인생 한 방 전 재산·숫자 1개·×8·틀리면 쪽박(빈곤 농장) / 🔥 반반 승부 / 🪙 소소한 재미 / 🏖️ 조기 은퇴 / 🍵 지나가기, 🍀 행운 아이템이면 숫자 +1), 🏆 노년 대회(능력치 + 그 대회 아이템), 🔨 골동품 경매(아이템·보물을 망치 룰렛 ×0.5~×3), 모든 아이템의 「👴 노년 활용」(상점 카드에 표시), 청년·중년 상점 칸 복귀(아이템 2개 진열), ⏰ 노년 마감(40칸 → 최대 12턴: 실력 룰렛 「항상 1」로 노년 칸을 더 밟던 전략 13.8–21.3 → 1.9–5.0 %), 역전 기록·칭호 5종·MC 6상황. 측정: 노년 턴 중 선택 있는 턴 27.8 → 51–55 %, 선택 없는 연속 턴 최장 중앙값 13 → 4–6, 노년 룰렛 8.1 → 7.8회, 고수의 「노년 시작 하위 절반 → 1위」 0 → 22–30 %, 노년 결투 지배 전략 없음, `--aim-duel` 강한 CPU 23–29 % 최고·고정 조준 ≤ 15.6 %, `cpu-game --matrix` 두 세계 모든 목표 ✅(평범 1 + 3: 95.5 / 93.5 %), 보통 난이도는 실력 룰렛 조준을 사람처럼(`cpu.levels.normal.aimRandom` 0.5 → 1, 실력 룰렛 방 평범 1 + 3: 16.5–24 → 26.5–28 %). 사실은 CLAUDE.md "Senior race comeback (노년 역전)".
