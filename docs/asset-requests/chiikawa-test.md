# 치이카와 그림 테스트 요청 (로컬 Gemini 스킬용)

게임 그림을 치이카와 그림체로 바꾸기 전에, 로컬 PC의 Gemini 스킬로 필요한 그림이 나오는지 10장으로 확인합니다.

## 로컬 Claude에게 시킬 일
1. 브랜치 `claude/admiring-gates-1qlocc`를 받습니다(`git pull`).
2. `docs/asset-requests/chiikawa-test.json`의 `items`를 순서대로 생성합니다.
   - 프롬프트의 `{{style}}`은 파일 위쪽 `style` 문장으로, `{{canvas}}`는 항목의 `canvas`가 가리키는 `common` 문장(또는 항목에 직접 적힌 문장)으로 바꿉니다.
   - `refs`에 적힌 id는 **먼저 만든 그 그림을 참조 이미지로 첨부**합니다(편집 요청). 참조 첨부가 안 되면 그 사실을 기록하고 프롬프트만으로 생성합니다.
   - 같은 항목을 여러 번 뽑을 수 있으면 2장까지 만들어 `<id>.png`, `<id>-2.png`로 저장합니다.
3. 결과를 `assets-inbox/test/<id>.png`로 저장하고 커밋·푸시합니다. (`assets-inbox/test/`는 git에 올라가도록 설정해 두었습니다.)
4. 아래 질문에 답을 `assets-inbox/test/REPORT.md`로 남깁니다.

## 확인하고 싶은 것 (REPORT.md에 적어 주세요)
- 거절된 항목이 있었나요? (캐릭터 이름 때문에 막혔는지)
- 참조 이미지(편집)가 됐나요? 편집 결과에서 캐릭터 위치·크기가 그대로 유지됐나요?
- 배경이 순수한 마젠타(#FF00FF)로 나왔나요? 그림자가 생겼나요?
- 2×2 스프라이트 시트에서 네 칸의 캐릭터 크기·위치가 비슷했나요?
- 한 장당 걸린 시간, 하루에 만들 수 있는 양(한도), 비용이 드는지.
- 이미지 해상도와 형식, 워터마크(✦ 반짝이)가 찍혔는지.
